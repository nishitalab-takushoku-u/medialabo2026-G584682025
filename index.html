「Webコンテンツ作成」の成果

本テーマについて

本テーマは、HTML, CSS, JavaScript の基本を学び、簡単なWebページを作成できるようになることです。Webページの構造や見た目を設定し、処理を記述する基本的な方法を学んでいきます。

プロジェクト課題について

私は、世界の天気を調べるWebページを作りました。 このページは、都市名がチェックボックスになっています。そのため、知りたい国を選択することで、その都市の天気を簡単に調べることができます。また、一度に複数を同時に選択することができるため、知りたい都市ごとの天気を一画面で簡単に見比べることができます。また、選択した都市ごとに一つの枠でまとめて入れるため見やすいようになっています。

プロジェクトで制作したページ: project.html

数当てゲーム

このページは、あらかじめランダムに出力された数字がコンソール上に表示されています。このコンソール上に表示されている『1〜9のランダムな数字』を予想し、当てるゲームです。テキストボックスに自身が予想した数字を記入し、コンソール上に表示されている数字と同じかどうかを判定します。判定の結果が違う場合は、入力した数字とコンソール上の数字を比較します。さらに、入力した数字がコンソール上の数字より大きいか小さいかを調べ、その結果を表示します。3回以内にクリアすると『正解です。』と表示されます。また、4回以上は正しい答えが表示されるようになっています。

数当てゲームのページ: kazuate.html

各授業回の学習事項

第1回 WWW と HTML

今回はHTMLの書式について学びました。気を付ける点は、タグ要素の使い分けとバグ発見のしにくさです。ブロック要素の中にインライン要素を入れることは可能ですが、逆の配置はできません。また、エラーが発生した場合、HTMLはエラーを出さないため、誤りが分かりにくいです。

学習の成果: 演習1-4: HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

今回はCSSによる見た目の設定について学びました。CSSで装飾するところを記述した際に一度に複数を変えることが出来ます。しかし、要素の中の一つのみを変える際には、クラスで名前をつけるなどして、全てが変化しないようにする必要があります。

学習の成果: 演習2-3: ウェブブラウザ説明ページの装飾

第3回 JavaSpript の基本

今回はJavaScriptとJavaの違いについて学びました。JavaScriptはコンパイルエラーになりません。実行時エラーは表示場所とは限らないため、間違いを見つけるのが大変です。そのため、コンソールで実行してエラーにならなかったものをそのまま使うことでエラーの発生を防ぎます。

学習の成果: 演習3-6: オブジェクトの参照

第4回 DOMとJavaSpript

今回はテキストボックスやボタンを設置して、ボタンを押した後の処理について学びました。ボタンを押した後に、コンソールやテキストボックスの下のメッセージを変更し、メッセージを出しました。inputのtypeによってボックスの種類が変わるため、より適したものを選べるようにしたいです。

学習の成果: 演習4-10: 足し算ページ

第5回 イベント処理

今回はボタンを押した後に要素の作成や削除、属性の変更を学びました。書き方によって順番や文字の大きさ、文字の出方などが変わってしまうため気をつけて書くことが大事です。自分の想像する順序に画面が動くように作っていきたいです。

学習の成果: 演習5-5: DOMプログラミング

第6回 プロジェクト課題

今回は、プロジェクト課題で独自のページを作成しました。思った表示にならない時は、JavaScriptのコード編集や処理の並び替えを行い、試行錯誤しながら理想の形に仕上げました。まだ改善できる点があるため、引き続き見直しと修正を行っていきたいです。

まとめ

工夫点

工夫した点は、検索方法をチェックボックスにすることです。 テキストからの入力は、カタカナやローマ字などユーザごとによって打ち方が異なっている場合がありますが、チェックボックスにすることで、検索方法を一つに絞り、文字を入力するという手間を省いて検索が簡単に行えるようにしました。 また、複数選択ができるチェックボックスにすることで、知りたい都市ごとの天気を一度で簡単に見比べることができるようにしました。 さらに、選択した都市ごとに一つの枠でまとめて入れる画面設計にしたため、他人が見ても非常に見やすくなっています。

苦心点

プロジェクト課題で、選択したものを表示させる際に、まとめて都市名が先に表示されてから、『経度』、『緯度』などが表示されてしまったり、検索結果の件数が再度検索したときにリセットされなかったり、この検索結果の文が検索結果の上に出したいところを一番下に表示してしまったりしたところで苦労しました。 そのため何度も、JavaScriptの中のプログラムの順番を変えながら、どのように結果が変化するのか確認しつつ編集を行いました。

強調点

強調したい部分は、都市名を複数選択し検索した際に、検索結果で都市名ごとに一つの枠でまとめて入れられており、横並びになるようにした点です。 高さを揃えることでそれぞれの項目を見比べやすいようになっています。 また、枠のサイズを指定したことにより、基本の大きさに変化がないようにしました。 さらに、名前が長いために枠が大きくなってしまう都市があっても、文字がはみ出して読めなくなるトラブルを防ぎ、情報がすべて綺麗に枠内に収まって他人が見ても快適に読めるようにしました。

感想

色変えたり、レイアウトを変えたりすることで見やすくなったり、反対にわかりにくいWebページになってしまうのだと感じました。 毎講義ごとに、プロジェクト課題を少しずつ変更していきました。 初めの方は、難しいと感じることが少なかったです。 しかし、JavaScriptに入った時ぐらいから、操作が多く、難しいと感じる部分が出てきました。 難しいところもありましたが、過去の講義資料を見直しながら仕上げることができてよかったと感じました。 自分の考えているページに仕上げられなかった時や、バグが発生してしまった時にJavaScriptのコードの編集や順番の変更を何度も行っていたことでもう一度似たようなことに遭遇してしまった際に、原因はここなのではないのかと思いつくようになりました。 今回のプロジェクト課題は、一番簡単なものを選んで課題を進めてきました。 しかし、他の課題は、実際に文字を入力してみたり、調べる部分が二つあったりなどもっと難しくなるため、そういった部分も扱えるように勉強していきたいです。
