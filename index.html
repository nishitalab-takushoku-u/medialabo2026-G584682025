「Webコンテンツ作成」の成果

本テーマについて

本テーマは、HTML, CSS, JavaScript の基本を学び、簡単なWebページを作成できるようになることです。Webページの構造や見た目を設定し、処理を記述する基本的な方法を学んでいきます。

プロジェクト課題について

プロジェクトで制作したページ: project.html

数当てゲーム

数当てゲームのページ: kazuate.html

各授業回の学習事項

第1回 WWW と HTML

今回はHTMLの書式について学びました。気を付ける点は、タグ要素の使い分けとバグ発見のしにくさです。ブロック要素の中にインライン要素を入れることは可能ですが、逆の配置はできません。また、エラーが発生した場合、HTMLはエラーを出さないため、誤りが分かりにくいです。

学習の成果: 演習1-4: HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

今回はCSSによる見た目の設定について学びました。CSSで装飾するところを記述した際に一度に複数を変えることが出来ます。しかし、要素の中の一つのみを変える際には、クラスで名前をつけるなどして、全てが変化しないようにする必要があります。

学習の成果: 演習2-3: ウェブブラウザ説明ページの装飾

第3回 JavaSpript の基本

今回はJavaScriptとJavaの違いについて学びました。JavaScriptはコンパイルエラーになりません。実行時エラーは表示場所とは限らないため、間違いを見つけるのが大変です。そのため、コンソールで実行してエラーにならなかったものをそのまま使うことでエラーの発生を防ぎます。

学習の成果: 演習3-6: オブジェクトの参照

第4回 DOMとJavaSpript

今回はテキストボックスやボタンを設置して、ボタンを押した後の処理について学びました。ボタンを押した後に、コンソールやテキストボックスの下のメッセージを変更し、メッセージを出しました。inputのtypeによってボックスの種類が変わるため、より適したものを選べるようにしたいです。

学習の成果: 演習4-10: 足し算ページ

第5回 イベント処理

今回はボタンを押した後に要素の作成や削除、属性の変更を学びました。書き方によって順番や文字の大きさ、文字の出方などが変わってしまうため気をつけて書くことが大事です。自分の想像する順序に画面が動くように作っていきたいです。

学習の成果: 演習5-5: DOMプログラミング
